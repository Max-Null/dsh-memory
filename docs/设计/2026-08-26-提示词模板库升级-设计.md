> 日期：2026-08-26
> 状态：待评审

> 参考实现：0070099999/dsh-prompt-library（agent 检索工具 + md 元数据）、subingbo/dsh-client-prompt-library（sidebar.footer.action 插槽论证 + 输入框光标插入）

## 一、目标与非目标

**目标**：提示词模板成为 dsh-memory 的第一等能力——同样的明文可查、同样的人工可控、同样的「模型可检索、用户可管理」，但不引入新插件与新存储引擎。

**非目标**：
- 不做模板的系统 prompt 注入（模板永不注入，见 §三）；
- 不做独立 3090 服务（零外部服务）；
- 不做云端同步/分享（本地文件即分享媒介：拷走 `.md` 即可）。

## 二、存储设计：md 文件是唯一事实源

### 2.1 文件布局

```text
~/.dsh/prompt-library/global/<seq>_<名称>.md
<workspace>/.dsh/prompt-library/<seq>_<名称>.md   # project 随工作区（与记忆同构，git 可分享）
```

- 用户可直接放入/编辑/删除 `.md`（命名约定 `序号_名称.md`，序号 4 位数字，冲突时取下一个空号）；
- 手工编辑即时生效（引擎按 mtime 惰性刷新索引，见 §2.3）。

### 2.2 文件格式（UTF-8，frontmatter + 正文）

```markdown
---
seq: 36
name: "台风天气内容生成"
dimension: "前端"            # 维度：前端/后端/全栈/物理/逻辑/学科知识/Rust 等（自由文本）
difficulty: "L3"            # 难度：L1~L5 / LX / LXX（自由文本）
tags: ["Three.js", "台风"]   # 标签，检索过滤用
source: "user"              # user=用户创建；agent=模型新增（UI 角标提示）
createdAt: 2026-08-26
---

(主提示词全文)

---

备用提示词2

(可选，备用提示词)
```

**schema 校验**：frontmatter 解析失败/缺 name → 该文件跳过并记警告（不崩、不索引），文档明示格式；解析与校验规则集中在一个模块（`src/prompt-files.ts`），单测覆盖坏文件、空文件、缺字段。

### 2.3 索引设计：memory 存储中的 prompt 记录

`MemoryRecord` 扩展两个可选字段（旧数据缺省即向下兼容）：

```ts
type MemoryKind = 'fact' | 'prompt'             // 缺省 'fact'
interface MemoryRecord {
  // ...现有字段
  kind?: MemoryKind
  meta?: {                                       // 仅 prompt
    seq: number
    path: string                                 // md 绝对路径
    mtime: number                                // 索引时的文件 mtime
    source: 'user' | 'agent'
  }
}
```

| 字段 | prompt 记录取值 |
|---|---|
| `content` | 名称 + 维度/难度/标签 + **摘要**（正文前 200 字）——BM25 检索用；全文由 `prompt_get` 直读文件 |
| `keywords` | 名称 + dimension + difficulty + tags（检索关键词域） |
| `status` | 恒 `approved`（**文件存在即生效**，见 §四决策论证） |
| `injected` | 恒 `false`（模板永不注入） |
| `id` | `prompt-<pathHash8>`（稳定；文件删除后条目随 forget 清理） |

**刷新规则**（惰性、零常驻 watcher）：
- 索引读取/`prompt_list`/`prompt_search` 触发 `refreshPromptIndex()`：扫描目录，对每个 md：mtime 变动 → 重建该条；新文件 → 建档；缺失文件 → 删除条目；
- 无文件变化时零 IO（缓存 mtime 比对）；
- 风险与后续：极高频写入场景可升级 watcher/chokidar（非目标，文档注明）。

## 三、决策论证（相对记忆流的三处刻意偏离）

| 点 | 记忆（fact） | 模板（prompt） | 理由 |
|---|---|---|---|
| 注入 | approved + injected 可常驻 | **永不注入**（injected 恒 false，UI 无开关） | 模板是"要贴的内容"而非"应知道的规则"；注入会浪费上下文 |
| 审核 | suggested → 人工 approved | **文件存在即生效**；模型新增打 `source: agent` 角标 | 模板不注入、不执行、无隐私面，风险等级低；"模型新增→用户删/改"比"先审后用"更顺（模板质量可迭代） |
| 删除 | forget 删除记录 | 删文件即消失（索引同步清）；`memory_forget` 对 prompt 记录等价删索引（文件保留） | 文件是事实源，UI 删除操作提示「文件将一并删除」 |

（若评审认为模型新增也需闸门，可改 `source: agent` 的文件初始不入索引，人工在 UI 点「认可」后建索引——实现预留开关。）

## 四、工具（host 侧 4 新 + 1 扩展）

```ts
// 新增（全部走 ctx.memory，复用 BM25 + kind 过滤）
prompt_search(query: string, filter?: { dimension?, difficulty?, tags?, name? }, namespace?)  // → 命中列表（name/维度/难度/标签/摘要/score）
prompt_get(nameOrId: string)                                                                  // → 完整 md（正文 + 备用提示词 + 全文 meta）
prompt_list(filter?: { dimension?, difficulty?, tags?, namespace? })                          // → 索引列表（不含全文）
prompt_add({ name, dimension, difficulty, tags, content, fallback?, namespace? })             // → 写 md + 刷新索引（source: agent）

// 扩展：memory_search 增加 kind?: 'fact' | 'prompt'（缺省 'fact'，保持既有行为不变）
```

- 错误语义：`prompt_get` 未命中 → 明确 error（附最近列表建议）；维度/标签未知值不报错（自由文本）；
- 关键词生成：名称 + 元数据 + 正文摘要分词（复用现有 bm25 分词管线，无新依赖）。

## 五、UI（记忆面板内新 tab）

```text
侧栏记忆面板（现有）
└─ 顶部：namespace 行（global / project）
   └─ 内容区 tabs：〔记忆〕〔模板〕          ← 新增，面板内切换（不新增侧栏按钮）
```

**模板 tab**：
- 筛选 chips：维度 / 难度 / 标签（多选，来自索引词频 Top-N）
- 列表行：名称 · 维度 · 难度 · `agent` 角标（source=agent）· 更新时间
- 操作：**预览**（展开摘要）→ **插入输入框**（光标位置，保留撤销链）· 编辑（引导打开 md 文件/内联表单二选一，v1 做「编辑表单」覆盖全字段）· 删除（提示文件一并删除）
- 底部「+ 新增模板」表单（名称/维度/难度/标签/正文/备用提示词 → 写 md，source: user）
- 语言：随 DSH zh/en（现有 STRINGS 结构内扩展）

**插入输入框实现**（v1 必须先验证）：复用 `dsh-draft-polish` 的 draft 通道（其 client 有 setDraft/server 服务）——若该服务不可复用，降级为「复制到剪贴板」并在文档标注；实现时先做 10 分钟 spike 验证（读 dsh-draft-polish 源码确认注入接口与插槽），**验证失败不阻塞 M1/M2**。

## 六、迁移与兼容

- 旧 memory.json 记录无 `kind` → 读时归一为 `fact`（与 0.4.x 的 auto/suggest 迁移同款一次性转换，不重写文件）；
- `memory_*` 既有 6 工具行为零变化（仅 memory_search 增可选参数）；
- 模板目录不存在 → 全部 prompt 能力为空列表 + 首次创建自动建目录。

## 七、发版与 SSiD 预置链

- 版本：**0.6.0**（minor：新增能力面）
- npm 发布后 **SSiD profile-template pin 需显式升级 `@max-null/dsh-memory: ^0.6.0`**（`^0.5.2` 不跨 minor——发版流程规范 §1.2 陷阱），归档重建随下次 SSiD 发版自动携带；
- 本插件自身版本号同步 **vendor 不必**（dsh-memory 走 npm 声明，非 vendor 产物）；dev profile 由插件中心/`pnpm add` 更新。

## 九、风险与后备

| 风险 | 应对 |
|---|---|
| 插入输入框 API 不可复用 | 降级剪贴板；插入能力作为 M3 可选项 |
| 用户手改 md 与索引短暂不一致 | mtime 惰性刷新（秒级）；`prompt_list` 有手动「刷新索引」按钮 |
| frontmatter 手写易错 | UI 表单恒为权威写入路径；坏文件跳过 + 警告日志（~/.dsh/logs） |
| 大库性能 | 摘要索引（非全文入库）；200 文件级仅几十 KB，无压力 |
