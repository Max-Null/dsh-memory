# 决策：语义检索通道（`config.embeddings`）启用判据

> 日期：2026-09-18
> 状态：**判据已定，暂不启用**（观察中）
> 决策人：MaxNull（时机判断权委托给助手）
> 关联：`docs/决策/2026-08-15-DSH记忆插件-独立插件发布.md`（§二.3「语义检索留 v2，以『可观测 + 可修复』为门槛」）

---

## 一、背景

语义通道自 v0.5.2 起**已实现但默认关闭**：`bm25.ts` 提供 `cosineSimilarity` 与 `rrfFuse`，`engine.ts` 的 `semanticRanking()` 在配置 `config.embeddings` 时与 BM25 结果做 RRF 融合，未配置则走纯 BM25。语义侧抛错只 `warn` 并降级回 BM25 结果，不影响检索可用性。

2026-08-15 给 v2 定的门槛是「可观测 + 可修复」，现已满足：

- **可观测**：向量作为记录上的可选字段（`vector`）明文持久化，与正文字段同在；语义通道失败有日志。
- **可修复**：关掉配置即退回纯 BM25，记录本身不受损；备份与 `.polluted-*` 快照机制沿用既有存储层。

**门槛满足 ≠ 该启用。** 启用后的代价是实打实的：每条记忆（新增与更新）都要算向量、多一个外部依赖与失败面、换 embedding 模型需全量重算且新旧向量不可比。所以真正的问题是**时机**。

用户 2026-09-18 把时机判断权交给助手，理由：**「这个机制是给你用的，不是给我用的，鞋合不合适脚知道手和眼不知道。」**

## 二、现状基线（2026-09-18 实测）

| 指标 | 值 |
|---|---|
| `project` 库 | 90 条 / 158.7 KB（`<工作区>/.dsh/storages/memory_project_3rf76j.json`） |
| `global` 库 | 33 条（16 条记忆 + 17 个提示词模板）/ 51.9 KB |
| `keywords` 数量 | 平均 **10.0** 个（min 6 / max 23），**0 条无关键词** |
| `hitCount` | 平均 0.84，最大 2，25 条为 0 |
| `query-log.json` | 4 次查询，**0 次空命中**，`hits` = 20 / 75 / 86 / 94 |

**关键观察：空命中不是有效信号。** 中文 2-gram 下 BM25 几乎给全库打分——库 90 条时 `hits` 已达 94，等于没有筛选。因此本实现里「搜不到」不会表现为 `hits = 0`，而表现为**相关记录被淹没在几十条字符重叠里、进不了返回的 top-K**。

真正在干活的从来是**排序**，其次是**人工写进去的关键词**（平均 10 个，就是为字面匹配补偿的同义词表）。这两处才是指标所在。

## 三、判据（命中即建议启用）

1. **漏检案例累计 3 次（主判据）**：关键词已给足（≥10 个，含中英 / 同义词 / 缩写）却仍漏检——即返回结果里没有那条确信库中存在的记忆，需换两组以上措辞才找到。
2. **规模触发**：`project` 库超过 **300 条**时重新评估。排序淹没随库增长（任一 2-gram 的字符重叠面随库扩大），当前 90 条已近全命中，筛选压力全压在 BM25 排序上。
3. **用户反馈触发**：用户说出「之前不是说过吗 / 你不是记过吗」而检索没把它带出来——立即记案例，权重等同漏检一次。

单次漏检不构成启用理由：措辞偏、查询本身怪异都会造成偶发漏检；**3 次意味着词汇鸿沟是系统性的**，人工枚举补不住。

## 四、反向约束（不该据此启用）

- 漏检若属**知识缺口**（库里确实没有），语义通道同样救不了——该补记忆，不是开语义。用 `MemoryEngine.suggestKeywordGaps()`（`engine.ts`）反查可区分：候选 `exact = 0` 且 `relaxed = 0` = 知识缺口；候选有 `relaxed` 命中 = 措辞不匹配，**这才是语义通道的适用场景**。
- 该反查 API 目前**已实现但未接线**：无工具入口、无 UI 入口，只能手工读 `query-log.json` 再比对库内容。要定期体检需另立项接线。

## 五、委托与执行

- 判断权在助手：察觉到第三节任一信号时**当轮直接提出**并附证据（哪次查询、期望哪条、实际返回什么），不静默观察。
- 案例计数追加在下方「观察记录」，一条一行，含日期与查询原文。
- 反向也成立：**没有信号就不启用**。人工关键词目前是有效的工作投入，不是必须消灭的成本。
